## 🧪 About the Project

**Alchemize** is an experimental **emotional transmutation console**,  
a meditative command-line interface that turns feelings into fuel through interactive reflection.

It blends psychology, art, and code — creating a space where **data meets soul**.  
Every run is a short narrative: an emotional state is entered, processed, and *transformed*.

Shadow emotions (Pain, Fear, Doubt, Anger) are **refined into purpose**.  
Light emotions (Joy, Love, Peace, Gratitude, Confidence, Hope) are **amplified into energy**.

> “Every emotion is data — the art lies in how you process it.”

---

## 🌗 Features

- ⚙️ **Dual-Mode Alchemy:** Shadow ↔ Light transformation  
- 🌈 **Animated Console Output:** progress bars, glowing text, and pulsing effects  
- 🔮 **Synonym Recognition:** type *hurt*, *worry*, *calm*, or *bliss* — it understands  
- 🧭 **Interactive Menu:** pick emotions manually or flow intuitively  
- 💫 **Mindful UX:** slow-print text + subtle timing that promotes presence

## 🧰 Installation

```bash
# Clone this repository
git clone https://github.com/AlecWilliams27/alchemize-console.git
cd alchemize-console
```

# Create a virtual environment
/usr/bin/python3 -m venv .venv

# Activate it
source .venv/bin/activate  # macOS/Linux
# .venv\Scripts\activate    # Windows PowerShell

# Install dependencies
pip install -e .
🌞 Usage
python -m alchemize
or, if you added an alias:
alchemize
Once launched, you’ll be greeted by the Alchemy Console:
──────────────────────────────────────────────────────────────
                  ALCHEMY CONSOLE
──────────────────────────────────────────────────────────────
Type an emotion (pain, fear, doubt, anger | joy, love, peace…)
Choose what you’re feeling — and watch as your terminal transmutes emotion into insight.

⚗️ Behind the Code
“Alchemy is data transformation with a soul.”
Core Concepts
The progress bar mirrors transformation — pain becoming purpose.
ANSI color codes emulate light frequencies for emotional resonance.
Slow-print and delay loops simulate breathing and awareness pacing.
Shadow / Light sets model emotional polarity (Jungian inspiration).
Framework
Written in pure Python 3 (no external UI libraries).
Packaged as a self-contained CLI via python -m alchemize.
Designed for mindful interaction rather than speed.
